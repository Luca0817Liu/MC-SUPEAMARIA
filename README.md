# Minecraft Mario (Super Craft Bros - Vibrant Edition) 🎮

An elite, full-featured retro Mario platformer set inside a fully custom-textured pixelated Minecraft block engine. Built with modern high-performance React 19, TypeScript, Vite, and tailwindcss v4.

---

## 🌟 Core Gameplay Features

1. **Procedural Retro Canvas Engine**: Features real-time voxel block shading, pixelated grass canopy fringes, stone cracks, clay bricks, pipes, background clouds, and fluid dynamic player/enemy movement.
2. **Four Intense Stages**:
   - **World 1-1 (Classic Plains)**: Sunny weather with creepers and simple jumps.
   - **World 1-2 (Nether Underground)**: Brick-underworld layouts, magma cubes, and gold bricks.
   - **World 1-3 (Sky Void Islands)**: Intricate double-jump platforms and high-stakes dropoffs.
   - **World 1-4 (The End Boss Realm)**: Obsidian pillars, Ender Dragon Boss throwing heat-seeking fireballs, with ultimate portal flags!
3. **Immersive Audio Engine**: Hand-crafted square wave sound effects for stomps, jumping, damage, and separate stage-themed soundtracks.
4. **Fluid Input Controllers**: Comprehensive support for computer keyboard keys (`WASD`, arrow controllers, space jump) and high-touch dual-layout mobile digital D-PAD and buttons:
   - **A button** for jump & double jumping.
   - **B button** to shoot explosive fireball waves in Fire Form.

## 🚀 Newly Implemented Systems (Release v1.2)

### 1. Retro Tips Marquee Ticker 💡
Addressed the critical readability bug by introducing an elegant horizontal marquee container on the Retry Game Over screen, showcasing survival strategies like secret areas, powerup properties, and stage key setups.

### 2. Tactile Speed Control Panel ⚡ (New Feature!)
Equipped the Ticker with convenient speed mode indicators. Users can now click or tap any speed preset instantly to personalize their reading experience:
- **`||` (Pause)**: Completely halts character movement to analyze comprehensive tips.
- **`S` (Slow [0.5x])**: Gentle, highly relaxed horizontal scrolling (45 seconds cycle).
- **`M` (Normal [1.0x])**: Standard, comfortable reading speed (25 seconds cycle).
- **`F` (Fast [1.5x])**: High-velocity scrolling rotation (15 seconds cycle).
